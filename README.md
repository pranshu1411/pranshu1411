## Featured Projects

### [PulseQ](https://github.com/pranshu1411/PulseQ)

**Distributed Job Orchestration Platform**

An event-driven platform for processing computationally intensive background workloads, including CSV ingestion, image manipulation, and batch email campaigns.

- Peak throughput of **1,345 jobs/sec**.
- Supports workloads containing **50,000+ records**.
- Average queue latency of **69 ms** under benchmark conditions.
- Fault-tolerant execution with two-level dead-letter queues, exponential backoff, and isolated workers.
- Real-time execution telemetry using Socket.IO and Prometheus.
- Deployed on DigitalOcean with Docker, Nginx, and automated CI/CD.

`NestJS` `BullMQ` `Redis` `PostgreSQL` `React` `Docker` `Nginx` `Prometheus`

### [TeleShell](https://github.com/pranshu1411/TeleShell)

**Autonomous AI Coding Agent**

A stateful AI agent that navigates, understands, debugs, and modifies codebases through a CLI and Telegram bot.

- AST-based code retrieval that reduces LLM context-token consumption by approximately **90%**.
- Virtual filesystem overlay with human-in-the-loop approval for code modifications.
- Autonomous repository navigation, code generation, debugging, and multi-file refactoring.
- Background process orchestration, execution logs, and iterative self-correction.

`TypeScript` `Bun` `OpenRouter` `ts-morph` `Telegram Bot API`

### QSDO-SC-ANFIS

**Explainable AI for Cardiovascular Disease Prediction**

A research project combining metaheuristic optimization with adaptive neuro-fuzzy inference systems for feature selection, hyperparameter tuning, and interpretable clinical predictions.

- Evaluated across three clinical datasets using 25-seed budget-matched experiments.
- Benchmarked against five machine learning models and two metaheuristic algorithms.
- Achieved **75.8% accuracy**, **0.82 AUC**, and **0.73 F1-score** on the Statlog dataset.
- Extracted human-readable fuzzy medical rules for clinical interpretability.

`Python` `MATLAB` `Machine Learning` `ANFIS` `Metaheuristic Optimization`
